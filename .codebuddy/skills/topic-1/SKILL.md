# 单条深挖（topic-1）

输入是一个链接或一个话题，输出是**一条**把来龙去脉和缺口讲透的深挖稿。文风与红线统一遵循 `.codebuddy/skills/everynews-editorial/SKILL.md`。

## 1 · 四路检索

1. **官方原文**：公告 / 博客 / 论文 / 仓库，唯一直接引用口径。
2. **交叉报道 ≥2 家**：核对金额、日期与口径差异。
3. **社区讨论**：HN、Reddit、X 公开讨论与中文社区，找真正在吵的分歧点。
4. **反方与缺口**：专门找原文没写全的限制、成本或样本条件。

## 2 · 沉淀事实底稿与讨论地图

写清核心结论、时间主体、精确数字（含单位与口径）、未确认项，以及正反双方真正的分歧点。

## 3 · 写稿与配图

- 调用 `everynews-editorial` 写单一连贯正文（第一句带主语和动作直接入题，不写标题党短钩子分段，零冒号破折号翻案腔），末尾附主来源完整 URL。
- 如需配图，按 `工具/PROMPT.md` 做 1–2 张高密度信息卡（`./工具/make.sh <slug>` 自动生成 PNG + WebP）。
