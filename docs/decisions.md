## 本地优先的出稿路径

- 日期：2026-11-07 更新
- 出稿、闸门、单文件页都在本机完成，依赖 `node`、`python3`、`playwright-cli`。
- 出稿契约是 `./出稿.sh <YYYY-MM-DD> <slug...>`。当天目录只留 `文案.md`、`配图/`、`预览图.png`、`X热议.md`；复审回执在 `工具/复审/<日期>.md`。
- `make-public.mjs` 出根目录 `<YYYYMMDD>.html`，`make-index.mjs` 注入期次导航、同步 `index.html` 并生成 `archive.html`，两者都由 `出稿.sh` 自动调用。主页是当日成果的完整内容，往期公开页一律保留。
- 预览图是公开页的整页截图。旧的 `preview.html`、卡片拼图与 `site/` 多期站方案已移除。
- GitHub Pages 只托管已经生成的静态 HTML。

## 写稿顺序靠文件，不靠自觉

- 日期：2026-11-07
- 起因：11-07 那批动笔前先排了开头／收尾组合再往里填，六条长成同一个模具；三遍复审又被当成写前计划表。规则 §4.1 早有禁令，但只写在文档里，执行时跳过了。
- 立意稿落在 `工具/立意/<日期>.md`，必须早于 `<日期>/文案.md` 落盘。日期目录仍只留四项，不新增当天产物。
- `工具/check-voice.mjs` 同时验顺序（存在、mtime、六句与首句的词面关联）与五类 AI 味（首句模具、段数同款、末句建议腔、跨条套话、讲解对仗），接成 `出稿.sh` 渲染前的首道闸门。
- 检查器不提供阈值参数，命中只能改稿。`--voice-only` 只用于回看历史批次，不能当本轮放行。
- 脚本只覆盖可数的模具痕迹，「没有活人感」仍靠 `WRITING.md` §7.3 三遍人工复审。
